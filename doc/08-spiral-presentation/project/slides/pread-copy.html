The CPU copies the 4 KiB from the page cache into your buffer: copy number two, every byte through the CPU. Then pread returns and your code runs again. That is every read: two copies, two context switches. The same 4 KiB now sits in memory twice. Mention the cost in one breath: the DMA writes each byte once, the CPU copy reads and writes it again, so every byte crosses the memory bus three times. Say memory moves 100 GB/s and the SSDs read 50 GB/s: pread's copies alone ask for 150 GB/s, more than the machine has, before any query work. If asked for a measurement: t4 on 12 SSDs read about 13 GiB/s with copies on its read path (zeroing a third of the time, copying over a quarter, page faults a fifth), and 34.6 GiB/s reading straight into the caller's buffer, 98% of the drives (doc/04-multi-device.md).
