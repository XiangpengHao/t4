What we have: ClickBench's 43 queries over the single file, DataFusion with 88 partitions, page cache dropped before each run, warm pass. Page cache 15.27 s, t4's memory tier 15.31 s, t4's disk tier on twelve SSDs 14.93 s, on one SSD 21.95 s. On twelve SSDs the queries run as fast as from memory; on one they take 44% longer, all of it in the scans of many columns. One run each: queries that read nothing off the drives differ by up to a third between runs, so read the totals. On the i7i with 192 partitions the warm pass took 11.99 s from the page cache and 12.19 s from t4's disk tier (doc/04-multi-device.md).
