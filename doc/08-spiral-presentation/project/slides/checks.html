Speed only counts if the bytes are right. The rule: a cache may lose any block, since the object store has it, but it must never return wrong bytes. Proved: Verus proves the free-chunk bitmap and the block and page arithmetic, from a file's blocks to a read's pages (src/cache/storage/chunks, src/cache/storage/index). Replayable: every concurrent test runs under shuttle with seeded PCT schedules, the seeds checked in, on a simulated disk, socket and clock (doc/12-seeded-concurrency-tests.md). Fuzzed weekly: every Monday in CI, an hour per target from an empty corpus (.github/workflows/fuzz.yml). cache_equivalence checks every read against the store, through restarts on moving cache files and kills; shared_mode and shared_owner run an owner and its clients, one client sending whatever frames the input picks; frames and log_base fuzz the socket's frames and the log's base. The same job runs every shuttle test for 50 minutes on new seeds.
