INTERNAL · i3en.2xlarge, 2 SSDs · VORTEX DATAFUSION BENCH · 28 OCT 2026 · live: t4 Disk Tier Across Boxes

The small instance, run after run: TPC-H q6 and q19 from an i3en.2xlarge's two SSDs as one RAID0, thirty runs in one process after a first, each process after a 45-second rest; the first run, Vortex's start-up and t4's fill from S3, is left out. Right after the rest the drives read several times faster than their steady rate, so the first runs are fast. Vortex falls to the steady rate within two or three runs; t4 later, because it reads half the bytes a run. Why half: Vortex reads through the page cache with the RAID's default 2 MiB readahead, so for q6 the drives read 822 MB when Vortex asked for 400; t4's direct reads take exactly the 399 MB it needs. At the steady rate t4 takes 307 ms against Vortex's 594 on q6, and 391 against 715 on q19. Medians of the last five runs, 28 Oct 2026 (dashboard: t4 Disk Tier Across Boxes, Run after run).
