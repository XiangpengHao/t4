This is why the title can be true. Vortex reading from memory and t4 reading from SSD have the same job: get a file's bytes into the reader's read buffer. On the left, Vortex reads through the operating system: the bytes are already in the page cache, in kernel memory. On the right, t4 reads with io_uring and direct I/O: the bytes are still on the SSD. Memory looks like it should win.
