Cloud instances come with several local SSDs. Usually you'd build a RAID0 to use them as one. t4 stripes over them itself: you give it files and sizes, chunk c goes to file c mod n, and one I/O thread serves all of them. On an i7i.48xlarge, twelve drives read 47.8 GiB/s through t4, 94% of what fio reads from them (ClickBench replay, warm pass, 23 Oct). If asked: on a Z3, three drives read 2.9 times what one does, 98% of their cap. Why not RAID0: a failed drive takes the whole array with no copy to read from, and it needs root before t4 runs (doc/04-multi-device.md).
