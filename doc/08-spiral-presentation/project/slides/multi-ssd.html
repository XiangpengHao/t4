Cloud instances come with several local SSDs. Usually you'd build a RAID0 to use them as one. t4 supports many devices itself: you give it files and sizes, chunk c goes to file c mod n, and one I/O worker serves all of them. Three Z3 drives read 2.9 times what one does, 8,862 against 3,076 MiB/s, 98% of their cap, with one thread (z3-highmem-22-highlssd, 22 Oct). Twelve i7i drives read 47.8 GiB/s through t4, 94% of fio. RAID0 was rejected: a failed drive takes the whole array with no copy to read from, and it needs root before t4 runs (doc/04-multi-device.md). Optional: mention racing reads on SSDs as well.
