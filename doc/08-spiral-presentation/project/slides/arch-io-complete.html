As each read finishes, the kernel puts a completion into the completion queue. Each completion carries the request's tag, so the worker knows which task it belongs to (src/io/common.rs). If asked: the SSD has already written the bytes into the buffer by DMA before the completion appears. The slides show the bytes arriving when the task wakes, because that is when the task gets its buffer back: the worker holds each read's buffer while it is in flight and hands it back with the result.
