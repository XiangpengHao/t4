Queries read blocks 0 to 3. Each is fetched from S3 once, and a policy decides where it goes: memory, disk, or nowhere. The policy is a trait the user can supply; it hears of every remote read (on_remote_read). The default, a CLOCK per tier, puts fetched blocks in memory. Each lands in any free chunk, and its entry appears in the tree (doc/03-cache.md, decision 7). Memory is now full.
