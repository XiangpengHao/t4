Once the SSDs outrun what a query asks for, reading from disk costs nothing extra.

The cost model. How many bytes does a query read off the drives, and how long does it take from memory? If the drives deliver those bytes faster than that, and we do nothing stupid, the query from disk should take as long as from memory; if not, it takes bytes over the drives' steady rate. ClickBench query 22 reads 5.4 GB off the SSDs. On the small i3en.2xlarge, whose two drives read 1.36 GB/s steady, that is 3.9 s, more than the 3.6 s it takes from memory: the model says 3.9 s and t4 measured 4.1 s. On the i7ie.12xlarge, 12.7 GB/s, the bytes take 0.43 s, less than the 0.52 s from memory: the model says memory's time, and t4 measured 0.49 s. Times are medians of the last five of twelve runs back to back.
