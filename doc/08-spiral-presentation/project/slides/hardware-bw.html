Each dot is one AWS instance type with local NVMe. x: all its local SSDs read together, GB/s. y: its whole-instance memory read bandwidth divided by its physical CPU cores (AWS's instance-type tables; Intel and AMD instances run 2 threads per core, Graviton 1). Label: on-demand Linux price in us-east-1, per hour (AWS price file, 27 Oct 2026). SSD: ScyllaDB's measured read_bandwidth per disk times the disk count (scylladb/scylla-machine-image, common/aws_io_params.yaml, iotune over RAID0 of all disks); i7i.48xlarge is our own fio, 1 MiB direct reads on all 12 drives, 53.8 GB/s. Memory: Spare Cores' lmbench bw_mem read with one copy per vCPU, 512 MB (keeper.sparecores.net); on Graviton3 it reads about 7% above STREAM Triad. The point for the talk: a core gets only a few GB/s of memory bandwidth as its share, while one box's SSDs read tens of GB/s; on i7i.48xlarge the SSDs read about as much as 9 cores' share of memory.
