Three places a block can be. Memory is an array of 1 MiB chunks, taken once at startup. Disk is another array of 1 MiB chunks, in cache files preallocated on the SSDs and striped over them. Any free chunk holds any block, so nothing fragments. The remote is the file itself, in S3 or GCS: it always has every block. A block lives in exactly one of memory or disk, never both: the tiers are exclusive. Real tiers have thousands of chunks; four and six keep the picture readable.
