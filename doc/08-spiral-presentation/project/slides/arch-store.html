One index, three tiers

DataFusion and Vortex call t4 through object_store’s ObjectStore trait.

t4 · ObjectStore

the interface

Index: a bbtree

(file, 1 MiB block) → memory or disk

Memory

RAM, the smallest tier

Disk

Local SSDs, read with io_uring

Remote

S3 or GCS: the store t4 wraps

The t4 ObjectStore is the interface: DataFusion and Vortex read through object_store's trait and don't know t4 is there. Inside it, one bbtree index: paths maps a file's path to its version, and blocks maps (version, 1 MiB block) to a chunk in memory or on disk. The key is one u64, 40 version bits and 24 block bits (doc/03-cache.md). A block the index doesn't hold is read from the remote, which is the inner ObjectStore t4 wraps. Tiers are exclusive: a block lives in exactly one of them.
