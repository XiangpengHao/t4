Close on where t4 runs. Vortex: vortex-data/vortex#10954, a draft proof of concept, T4ReadAt and T4FileSystem in vortex-io behind a t4 feature, over t4's core API (doc/09-vortex-integration.md); it is for Vortex's maintainers to decide on. Spiral: t4 takes Kismet's place as spiral-io's local cache, and foyer, which was only Kismet's memory tier, goes with it; there is no switch back to Kismet (doc/10-spiral-integration.md). The disk tier survives a restart within one boot, and Studio and spiral connect share one cache through its owner. Check both PRs' state before the talk, and that the repo link is public.
